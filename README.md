## 一、游戏是什么

一款**纯前端 AI 推理互动小说**：玩家扮演侦探，调查城东码头三号仓库的周海平被害案。
核心玩法 = 档案阅读 → 时间线拼图 → 证据链审讯 → 提交结论，四段式闭环。

- **案件真相**：凶手王建国（王叔），动机 8 万元货款纠纷，手法铁撬棍击打头部。
- **时长**：演示模式完整通关约 20–40 分钟；LLM 模式时长由对话开放度决定。

## 二、玩法流程

| 阶段 | 内容 | 解锁条件 |
|---|---|---|
| 1. 档案室 | 翻阅 31 份档案（物证/证词/监控），标记已读；锁定档案显示"待解锁" | 初始开放 |
| 2. 时间线 | 事件卡**不显示时间**，需回档案室读档案找出每个事件的时间依据，再按先后排入时间轴并提交校验；排错时卡片会给出对应档案线索 | 档案室之后 |
| 3. 审讯室 | 与 3 名嫌疑人对话；出示已读档案击破其证词（证据链） | 时间线排对 ≥1 解锁王叔、≥5 李姐、≥10 小陈 |
| 4. 提交结论 | 选凶手 + 动机 + 手法，评分 S/A/B；满分才揭示完整真相，未满分只给方向性偏差提示 | 排对 ≥10 且击破任一嫌疑人 |

> 时间线推理设计（核心）：事件卡不显示时间，**档案也不直接写绝对时间戳**——31 份档案中仅 3 个锚点含绝对时间（饭店门口监控 20:20、验尸死亡时间 21:00–22:00、小陈火车票 18:40–21:30），其余档案全部用相对描述（"下班后吵架""打牌中途出去透气走了挺久""行车记录仪抵达码头后约3分钟画面被遮挡6分钟"）和顺序关系（监控只拍人物不拍时间戳，因安保员证词说明当晚监控时间戳故障）。**事件池展示顺序每次开局随机洗牌并存入存档**，玩家无法"从上往下依次点击"通关，必须组合多个档案推理事件先后。校验通过后时间轴才逐张揭示；校验失败时错误卡片直接给出"线索：查档案 xxx"，不罚时。

**证据链设计**（审讯核心，共 9 级）：
- 王叔 5 级：晚餐收据 → 老赵证词 → 后门监控 → 行车记录仪 → DNA 比对（每级击破后解锁下一档案，需回档案室阅读）
- 李姐 2 级：正门监控 → 钥匙登记表
- 小陈 2 级：火车票 → 手机短信
- 唯一伪证：arch_007（王叔首次证词与事实矛盾）。矛盾标记在**读齐全部反证且王叔已解锁审讯后**才显示，避免开局剧透。

## 四、AI 双模式

| 模式 | 引擎 | 特点 |
|---|---|---|
| 演示模式（参赛版默认） | 内置预置台词引擎 | 关键词 + 证据链分级回应，离线可玩、行为确定 |
| LLM 模式（在线版默认） | 项目 AI 网关（OpenAI Chat Completions 兼容） | 自由对话；对话发送至网关端点，网关端另设密钥与限流；Key 仅存 localStorage |

架构原则：**AI 只能"表演"（在预设剧情和谎言约束内自由发挥），不能"编剧"（篡改案件事实）**。
证据链命中时强制执行脚本台词，保证所有玩家都能推理出同一真相。

### 测试中修复的问题记录
1. `arch_023` 曾误配为锁定档案 → 改为无锁定（它是第 4 级出示证据）。
2. 演示 AI 浏览器环境拿不到 CASE（`const CASE` 是词法绑定非 window 属性）→ 环境适配改为全局引用 + Node 挂 global。
3. "杀"关键词缺失 → "人是不是你杀的"被判无关 → 补充关键词。
4. "见面/仓库"主题排序 → 翠湖/货款规则需在仓库规则后，避免误命中。
5. e2e 证据出示后需等待脚本台词延迟（400ms）再断言。
6. `getStatus` 在存档缺失 breakLevel 时崩溃 → 加 `|| 0` 防御。
7. 时间线玩法改造（第 1 轮）：事件卡原先直接标时间导致排序无推理价值 → 改为时间隐藏、线索藏档案、校验后揭示（含错误线索提示）。
8. 时间线玩法改造（第 2 轮）：档案原先直接写绝对时间戳，读档案=抄时间 → 全量重写为相对描述/顺序关系，仅保留 3 个时间锚点。
9. 时间线玩法改造（第 3 轮）：事件池展示顺序=正确顺序，可"依次点击"通关 → 开局 Fisher-Yates 洗牌并存入存档，清空时重新洗牌。
